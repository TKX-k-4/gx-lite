# Measuring memory (M1)

Compare GX Lite (Electron) and your Chromium build with the same pages. Fill in the table.

1. Close other browsers and big apps.
2. Open the same 5 tabs in each: a news article, YouTube (paused), a Google search, GitHub, a heavy web app.
3. Wait 2 minutes.
4. Record total memory of all the browser's processes.
   - Windows: Task Manager > Details, sort by name, add up all processes of the app (use "Memory (private working set)").
   - macOS: Activity Monitor, search the app name, add up its processes.
5. Repeat with 1 tab and with 10 tabs.
