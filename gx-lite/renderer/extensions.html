Extensions

Extension support did not start. Run npm install in the project folder and restart GX Lite.

Install extensions from the Chrome Web Store. GX Lite supports only part of Chrome's extension system, and it has no toolbar buttons for extensions yet, so use the Popup and Options buttons below. Extensions that run inside web pages (dark mode, ad blockers, page tools) are the most likely to work. Ones that need Chrome's toolbar, native apps or sign-in pop-ups may not.
